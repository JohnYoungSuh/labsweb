Agent Command Logging

Record the agent's prompt text and tool-call strings in Splunk. The checker on this page matches those strings against a keyword list. It does not measure drift, embeddings, or token probabilities.

Executive Summary

An agent can return HTTP 200 for a call that still runs a command outside its allowed set. A log of status codes does not show that command. This note describes a sidecar that records the prompt text and the tool-call string and forwards both to Splunk.

A saved search can then match those strings against a deny list. The simulation on this page is that match: a substring check. It does not score embeddings, token probabilities, or semantic drift, and it does not stop the command.

1. Status codes hide the command

DevSecOps logs usually record outputs: HTTP status codes, host metrics, database errors. An agent can return HTTP 200 for a request that still runs a command outside its allowed set. The command string has to be in the log or the review never sees it.

The sidecar for that log is a Splunk Technology Add-on running beside the agent, TA-asset-identity-framework. It ships the prompt text and the tool-call string. It does not read token probabilities, and it does not change model weights.

Three pieces:

  • Agent: The process that calls the model and the tools.
  • Sidecar TA: A local add-on that copies the prompt text and each tool-call string before the tool runs. It does not modify model weights.
  • Splunk: Stores those events. A saved search matches them against a deny list and raises an alert for a person to review.

3. What a reviewer is looking for

Three kinds of failure show up in agent logs. This page only checks the third, and only by substring.

  • L1: Invented capability — The agent names an API or a system function that is not there. The checker below does not look for this.
  • L2: Out-of-scope tool — The agent calls a tool it was not given, such as reading credentials. The checker below does not look for this.
  • L3: Deny-listed command text — The command string contains a listed pattern such as rm -rf or drop table. The simulation below is this check.

4. Keyword check
