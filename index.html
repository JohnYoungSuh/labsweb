// PROBLEM_01: PROMPT-ONLY AGENT DRIFT

Autonomous Agent Governance

Autonomous coding agents operating without mechanical gates suffer from semantic drift, reward hacking (writing passing tests that fail to assert), and non-deterministic tool coordination. Prompt rulebooks are probabilistic suggestions; stability requires frozen schemas, read-only TDD test mounts, Git worktrees, and deny-by-default sandbox egress.
