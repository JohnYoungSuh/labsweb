// GUIDELINES: REPORTING ISSUES & VULNERABILITIES

We follow responsible vulnerability disclosure and transparent open-source issue tracking:

  • Feature Requests & Public Bugs: Open an issue directly on the respective repository on GitHub detailing environment versions (Splunk Enterprise version, OS, browser).
  • Security & Vulnerability Reports: If you discover a security issue or unexpected privilege boundary defect, please email contact@suhlabs.com directly before public disclosure.
  • License & Freedom: All published SuhLabs compliance software and add-ons are released unconditionally under open-source licenses (MIT / Apache 2.0).
